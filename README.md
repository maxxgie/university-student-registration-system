# University Student Registration System

## About the Project
An Android-based student registration system developed as part of the CCS 3211 Mobile Systems Programming coursework at Dedan Kimathi University of Technology.

The system aims to enable first-year students to register for university services remotely, with support for offline registration and synchronisation when internet connectivity becomes available.

## Core Modules
- Student Registration
- Library Book Requests
- Hostel Accommodation
- Fees Payment through M-PESA

## Technologies
- Java
- XML
- Firebase
- Android Studio

## Team Development
This project is developed collaboratively using GitHub. Each team member works on a separate feature branch, with completed work integrated into the main branch through Pull Requests.
